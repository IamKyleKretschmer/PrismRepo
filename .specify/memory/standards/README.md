# Nintex Engineering Standards

These standards provide domain-specific guidance that supports the [Nintex Engineering Constitution](../constitution.md).

## Document Hierarchy

1. Constitution
   High-level, enduring engineering principles that apply across Nintex.
2. Standards
   Domain-specific requirements that apply across products, repositories, and technologies.
3. Implementation Guidance
   Concrete implementation patterns, approved profiles, examples, and platform-specific details.

## Current Standards

- [Authentication and Identity Standard](authentication-and-identity-standard.md)
- [Authentication and Identity Implementation Guidance](authentication-and-identity-implementation-guidance.md)

## Recommended Future Standards

- Secure Logging and Telemetry Standard
- Data Protection and Privacy Standard
- API Design and Compatibility Standard
- Reliability and Operational Resilience Standard
- Accessibility and Localisation Standard
- Testing and Verification Standard

## Usage

Use the constitution to understand what principles must always hold.
Use standards to understand what a domain requires.
Use implementation guidance to apply those requirements in a specific technical context.
