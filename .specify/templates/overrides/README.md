# Template overrides

This README is Prism's. Prism puts it back if it's missing, and never touches anything else in this folder.

Prism's SDD phases use one template each. A template here with the same name as one of Prism's, such as `spec-template.md`, `plan-template.md` or `tasks-template.md`, replaces Prism's template in full. Without one, Prism's own template is used, then Spec Kit's base template in `.specify/templates/`.

A template you put here stops getting Prism's improvements to it, so only override the ones you need to change.

For the full list of templates you can override, ask Prism's setup agent. It can also create an override from Prism's current template for you to edit, or bring an existing override up to date with changes Prism has made since.
