# Nintex Prism Docs

Use the Prism documentation in `docs/prism/` for setup, workflow guidance, and CLI details.

- [Overview](./docs/prism/overview.md) - High-level explanation of Prism goals, core concepts, and how CDD and SDD fit together.
- [Setup](./docs/prism/install/setup.md) - Set up Prism for a `multi-repo` or `single-repo` topology, configure solution context, and connect the code repos.
- [Choosing how to install Prism](./docs/prism/install/routes.md) - The CLI or the Prism plugin for Claude Code: how they differ, setting a project up with the plugin, and moving an existing project to it.
- [Prism CLI](./docs/prism/install/prism-cli.md) - Quick-start reference for Prism CLI installation.
- [Troubleshooting](./docs/prism/install/troubleshooting.md) - What Prism's session-start warnings mean and how to fix them.
- [CDD Journey](./docs/prism/cdd.md) - Lightweight, governed workflow for smaller free-form coding tasks.
- [SDD Journey](./docs/prism/sdd.md) - End-to-end spec-driven workflow from feature specification through planning, tasks, and implementation.
- [Best practices](./docs/prism/best-practices.md) - Recommended practice for working with Prism.
- [Glossary](./docs/prism/glossary.md) - Roles, topologies and other Prism terms.
- [Changelog](./docs/prism/changelog.md) - What changed in each Prism release.
